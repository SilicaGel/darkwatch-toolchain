# Project Skills

Project-local skills live in `.claude/skills/`. Invoke them by asking Claude to "use the [skill name] skill" or by reading the skill file directly.

| Skill              | File                                 | When to use                                                            |
| ------------------ | ------------------------------------ | ---------------------------------------------------------------------- |
| `update-changelog` | `.claude/skills/update-changelog/SKILL.md` | After a feature ships, bug is fixed, or feature is removed             |
| `update-handbook`  | `.claude/skills/update-handbook/SKILL.md`  | After a feature is added, changed, or removed                          |
| `update-brochure`  | `.claude/skills/update-brochure/SKILL.md`  | After a feature is added, changed, or removed — keeps the site current |
| `update-help`      | `.claude/skills/update-help/SKILL.md`      | After a client-facing feature is added, changed, or removed — keeps the in-app help page current |
